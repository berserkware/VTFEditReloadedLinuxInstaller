# VTFEdit Reloaded Linux Installer

This is a simple script to install [VTFEdit Reloaded](https://github.com/Sky-rym/VTFEdit-Reloaded) (running through wine) on Linux. It installs both the GUI and CLI. The code for the run scripts are adapted from the [Crowbar AUR Package](https://aur.archlinux.org/packages/crowbar). The scripts work fine on my computer, but may have still have issues, so run with care. You need `curl` and `wine` installed.
